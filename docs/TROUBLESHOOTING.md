# Troubleshooting

## অ্যাপ খুললে অ্যাক্টিভেশন স্ক্রিন আটকে যায়
MERQO-র কাছ থেকে পাওয়া `.merqolic` ফাইলটি নির্বাচন করুন। লাইসেন্সের ব্যবসার নাম
সেটআপে দেওয়া নামের সাথে মিলতে হবে। ডিভাইস পরিবর্তন হলে নতুন লাইসেন্স নিতে হবে —
"ডিভাইস তথ্য" বোতাম দিয়ে তথ্য ফাইল রপ্তানি করে MERQO-কে পাঠান। কোনো ইন্টারনেট প্রয়োজন নেই।

## প্রিভিউতে ডেভেলপমেন্ট লাইসেন্স পাওয়া যায়নি
`node scripts/dev/make-dev-license.mjs` চালিয়ে `private/dev-license.merqolic` তৈরি করুন
(এটি শুধুমাত্র স্থানীয় উন্নয়নের জন্য)। এরপর Vite প্রিভিউ রিফ্রেশ করুন।

## বিক্রয়ে "স্টকে পর্যাপ্ত পরিমাণ নেই"
পণ্যের স্টক `current_stock_minor` (৩ দশমিক) থেকে কমে গেছে। প্রথমে ক্রয় বা স্টক
অ্যাডজাস্টমেন্ট করে স্টক বাড়ান। ওজন/পরিমাণের একক রূপান্তর পরীক্ষা করুন।

## প্রিন্টার কাজ করছে না
ইনভয়েস ও রিসিট ডাটাবেজে সংরক্ষিত থাকেই; প্রিন্টার না থাকলে সেল বাতিল হয় না।
সেটিংস → রিসিট ও প্রিন্টার পাতায় ৫৮/৮০ মিমি প্রস্থ ও প্রিন্টার প্রোফাইল যাচাই করুন।
শুধুমাত্র তাপীয় রিসিট সমর্থিত; A4/A5 ইনভয়েস প্রিন্টিং নেই।

## ব্যাকআপ রিস্টোর ব্যর্থ
ফাইলটি `MERQOBAK` v1 কিনা, SHA-256 মিলছে কিনা এবং এনক্রিপ্টেড হলে পাসফ্রেজ সঠিক কিনা
যাচাই করুন ("যাচাই" বোতাম)। রিস্টোরের আগে স্বয়ংক্রিয় নিরাপত্তা ব্যাকআপ তৈরি হয়;
ব্যর্থ হলে সেটি ব্যবহার করে আগের অবস্থায় ফিরুন।

## ডাটাবেজ অখণ্ডতা সতর্কতা
`npm run db:verify` এবং অ্যাপের "সমন্বয় যাচাই" চালান। কোনো কিছু মুছবেন না; ব্যাকআপ নিয়ে
MERQO-র সহায়তায় অডিট লগসহ পর্যালোচনা করুন।

## সাধারণ ডেভেলপমেন্ট
`npm ci` → `npm run dev`. যদি `better-sqlite3` নেটিভ মডিউল ABI ত্রুটি দেয়,
`npm rebuild better-sqlite3` চালান (Windows-এ `electron-builder install-app-deps`)।
`npm test`, `npm run typecheck`, `npm run lint`, `npm run format:check` এবং
`npm run licenses` রিলিজের আগে বাধ্যতামূলক।
